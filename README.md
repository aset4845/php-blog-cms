# PHP Blog CMS

Простой блог-движок на чистом **PHP + MySQL** (без фреймворка): посты с обложками, картинками и видео, комментарии, настраиваемые кнопки навигации (разделы) и админ-панель.

## Возможности

- Публичная часть: список постов по разделам, страница поста с комментариями, встраивание видео (включая YouTube/Vimeo по ссылке)
- Комментарии к постам
- Настраиваемые кнопки навигации в шапке (разделы блога)
- Админ-панель: создание/редактирование/удаление постов, загрузка изображений и видео, вход по логину и паролю (с хешированием пароля и автовыходом по неактивности)

## Технологии

- PHP (PDO), MySQL
- HTML, CSS

## Структура проекта

```
php-blog/
├── admin/            # админ-панель (вход, дашборд, создание/редактирование постов, загрузка медиа)
├── includes/         # config.php, init.php (подключение к БД, сессия), функции, header/footer
├── public/           # точка входа для посетителей сайта (index.php, post.php, section.php)
├── sql/schema.sql     # базовая схема БД (posts, comments, header_buttons)
├── uploads/          # загруженные изображения и видео (не включены в репозиторий)
└── index.php         # редирект на public/
```

## Установка (XAMPP)

1. Скопируйте папку проекта в `C:\xampp\htdocs\`.
2. Запустите **Apache** и **MySQL** в XAMPP Control Panel.
3. Создайте базу данных `php_blog` и импортируйте `sql/schema.sql` через phpMyAdmin.
4. Добавьте таблицу пользователей для входа в админку (в дампе её нет):
   ```sql
   CREATE TABLE users (
       id INT AUTO_INCREMENT PRIMARY KEY,
       username VARCHAR(255) UNIQUE NOT NULL,
       password VARCHAR(255) NOT NULL
   );
   ```
5. Проверьте параметры подключения в `includes/config.php` (по умолчанию `root` без пароля).
6. Откройте `http://localhost/<папка_проекта>/admin/create_admin.php`, создайте администратора и **удалите этот файл** после использования (как и указано на самой странице).
7. Откройте сайт: `http://localhost/<папка_проекта>/`, админку: `http://localhost/<папка_проекта>/admin/login.php`.

> ⚠️ В коде (`public/index.php`, `admin/*`) встречаются обращения к колонке `posts.header_button_id` и таблице `media`, которых нет в `sql/schema.sql` — схема в репозитории не полностью синхронизирована с кодом. При разворачивании проекта может понадобиться доработать схему под актуальный код.
